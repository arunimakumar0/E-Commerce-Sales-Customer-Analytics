# E-Commerce Sales & Customer Analytics

## Overview

A Python-based data analytics project that analyzes e-commerce sales,
customer behavior, product performance and profitability.

## Objectives

- Analyze sales performance
- Identify top-performing products
- Analyze customer purchasing behavior
- Analyze location-wise revenue
- Evaluate salesperson performance
- Analyze profit and profit margins
- Identify sales trends

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Data Merging
4. Feature Engineering
5. Exploratory Data Analysis
6. Sales Analysis
7. Customer Analysis
8. Product Analysis
9. Location Analysis
10. Profit Analysis
11. Data Visualization

## Key Analysis

### Sales Analysis
Analyzed yearly and monthly revenue trends.

### Product Analysis
Identified products with the highest revenue, quantity sold and profit.

### Customer Analysis
Analyzed customer revenue, order frequency and repeat customers.

### Location Analysis
Compared revenue and profitability across locations.

### Salesperson Analysis
Evaluated salesperson performance using revenue, orders and profit.

## Conclusion

The project demonstrates the use of Python for data cleaning,
data transformation, exploratory analysis and business-oriented
data visualization.
